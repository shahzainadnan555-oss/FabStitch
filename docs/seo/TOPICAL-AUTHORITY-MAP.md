## Core topics and the page that should own them

| Topic              | Primary page                      | Supporting role                                                                 |
| ------------------ | --------------------------------- | ------------------------------------------------------------------------------- |
| Fabric marketplace | `/marketplace/`                   | Topic notes explain a search. They are not a second catalog.                    |
| Cotton             | `/collections/cotton/`            | Discover cotton pages explain a constraint. They do not replace the collection. |
| Linen              | `/collections/linen-lightweight/` | Same split.                                                                     |
| Silk               | `/collections/silk-sheer/`        | Same split.                                                                     |
| Denim              | `/collections/denim/`             | The lightweight denim cloth page owns that product name.                        |
| GSM / weight       | `/guides/fabric-weight-and-gsm/`  | Weight bands in the marketplace point here.                                     |
| Woven vs knit      | `/guides/woven-vs-knit-fabrics/`  | Construction topics point here.                                                 |
| Cotton vs linen    | `/guides/cotton-vs-linen/`        | Discover comparisons are the long form for other pairs.                         |
| Dress fabric       | `/fabrics/dress-fabric/`          | `/discover/fabric-for-dresses/` is the overlap to review.                       |
| Wholesale          | `/wholesale-fabric/`              | Marketplace sourcing notes support it.                                          |
| Fabric sourcing    | `/fabric-sourcing/`               | Buying and B2B topic notes support it.                                          |
| Fabric questions   | `/guides/fabric-questions/`       | Each question page answers one question.                                        |

Overlap risk is highest where a discover combination and a marketplace note explain the same fibre-garment pair. They should stay only if one is the essay and the other is the search note. They should not repeat the same paragraphs.
