## Repeated headings that were generic

These were the same string on every page in the template:

- Collection pages used "Inside this collection". Each collection H2 now names that collection.
- Best For product lists used "Best-fit FabStitch fabrics". Each list H2 now names the use.

Combination-topic pages still use a shared section shape. Their facts are slices of the parent fibre or garment, not a new essay. That is intentional. A full unique essay on every combination would recreate the mass-template problem.

## Pages that should not be merged just because the template matches

Fabric pages, collections, and Best For pages describe different cloths or different garments. A shared explanation of "do not invent a blank GSM" is a product rule, not a duplicate article.
